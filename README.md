# Java OOP Uygulamaları

Üniversitede nesne yönelimli programlama dersi için yaptığım Java projeleri.

## Projeler
- **banka_hesabi**: Hesap açma, para yatırma/çekme işlemlerini yapan konsol uygulaması.
- **stok_takip_sistemi**: Ürün ekleme, silme ve stok takibi yapan konsol uygulaması.

## Kullanılan kavramlar
class, object, constructor, set-get, encapsulation 

## Nasıl çalıştırılır
Java JDK kurulu olmalı. Proje klasörünü VS Code'da açıp Main.java dosyasını çalıştır.
